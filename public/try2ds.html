Help & Features
SRM VOXLOGIC — Digital Logic Design Simulator
SYSTEM ONLINE v2.0 — All Modules Loaded
🧩 Gate Palette
Drag AND, OR, NOT, NAND, NOR, XOR, XNOR, BUF gates onto the canvas. Also drag INPUT and OUTPUT nodes. Click any gate chip to preview its info. Double click the switches to on or off
🔬 12 Experiments
Click any experiment to load its circuit layout. Covers Logic Gates, Adders, Encoders, Flip-Flops, Counters and more. Each has a voice script in the Script tab.
⚡ Wiring
Press W or click the Wire tool. Click the output port of a gate, then the input port of another. A curved wire connects them.
🖱️ Canvas Controls
Scroll to zoom. Alt+Drag to pan. Drag gates to reposition. Double-click INPUT nodes to toggle 0↔1. Right-click any gate for context menu.
📊 Right Panel Tabs
Truth — live truth table
Info — gate description
Wave — signal waveform
Bool — Boolean expression
Script — voice narration
AI — AI Tutor chat
Keys — keyboard shortcuts
▶ Auto-Simulation
Click AUTO-SIM to cycle through all input combinations. Use STEP or press Space to advance manually. Adjust speed via dropdown.
🔊 Voice Narration
Click ◉ VOICE to enable text-to-speech. Open Script tab and click Narrate for step-by-step explanation.
🎙️ Voice Commands
Click MIC and speak: "simulate", "next experiment", "explain", "truth table", "zoom in", "undo", "dark mode".
✔ Circuit Checker
Click CHECK in toolbar to verify wiring. Detects unconnected inputs, missing outputs, and floating wires.
↓↑ Export / Import
Save your circuit as JSON using EXPORT. Load saved circuit using IMPORT. Perfect for saving lab work.
⚠️ AI Tutor — Rule-Based Responses
The AI Tutor uses a rule-based engine (no external API). For best results ask focused questions like:
✓ "What is an AND gate?"
✓ "Explain experiment 3"
✓ "What is my circuit?"
✓ "How does a full adder work?"
✘ Avoid vague questions like "tell me something"
